If you’re starting out with OpenId Connect (OIDC) , it can be confusing as to which flow you should use and what values you can expect to be returned. We’ve made life easier for you with a new OpenId Connect Inspector . The Inspector is quick to configure and enables you to try out the Implicit or Authorization Code flows using your own OneLogin OpenId Connect applications.
