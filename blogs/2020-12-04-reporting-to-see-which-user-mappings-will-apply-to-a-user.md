.blog-border { border: 1px solid #D5D5D5; padding: 10px; border-radius: 3px; } .blog-border.code { background: #f3f3f4; margin-bottom: 15px; } OneLogin administrators often wish to know an easy way to see which mappings will apply to a user. Until now, the only way was to use your mental brain power: memorize the user’s attributes and scan the shorthand conditions in your list of user mappings. It was very tedious at a minimum and impossible for mere mortals if you have dozens of user fields and one hundred mappings or more.
